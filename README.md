# Ecommerce Analytics SQL Project

## Project Overview

This project analyzes ecommerce sales, customers, products, and payments using SQL.

The project demonstrates advanced SQL concepts including aggregations, joins, subqueries, CTEs, window functions, views, GROUP BY, and HAVING.

## Database Tables

- CUSTOMERS
- CATEGORIES
- PRODUCTS
- ORDERS
- ORDER_DETAILS
- PAYMENTS

## SQL Concepts Used

### Aggregations
- SUM()
- AVG()
- COUNT()

### GROUP BY and HAVING
- Customer analysis by city
- Group filtering

### JOINS
- INNER JOIN
- LEFT JOIN

### SUBQUERIES
- Above-average customer spending analysis

### CTE (Common Table Expressions)
- Top spenders
- Revenue analysis

### WINDOW FUNCTIONS
- RANK()
- Running Total using OVER()

### VIEWS
- Customer Summary View

## How to Run

1. Create the database.
2. Execute ecommerce_analytics.sql.
3. Run analytical queries.
